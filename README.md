# yfinance-market-forecaster

An academic machine-learning application built with Python and Streamlit that uses historical stock-market data to train and compare three regression models, ultimately predicting the next trading day's closing price.

## 🚀 Features

- **End-to-End ML Pipeline**: Seamlessly fetches data, engineers features, trains models, evaluates metrics, and generates predictions.
- **Three Core Regression Models**:
  - Support Vector Regression (SVR)
  - Ridge Regression
  - HistGradientBoostingRegressor
- **Automated Model Selection**: Automatically compares models based on Root Mean Squared Error (RMSE) on a chronological test set.
- **Robust Cross-Validation**: Employs a strict 5-Fold TimeSeriesSplit to validate model stability and prevent time-based data leakage.
- **Currency Awareness**: Fully supports both domestic (NSE) and foreign stocks. Models train in the stock's native currency to preserve ML purity, while the UI seamlessly handles live foreign exchange (FX) conversions to display an INR equivalent.
- **Interactive UI**: A polished Streamlit dashboard featuring live stock lookups, Altair-powered historical charts, and transparent model evaluation metrics.

## 🏗 Architecture

The project follows a cleanly separated **Modular Monolithic Architecture**:
- **`src/data/`**: Manages data retrieval via `yfinance` and enforces strict data validation rules.
- **`src/features/`**: Handles feature engineering (e.g., OHLCV and historical lag features) while strictly preventing future data leakage by correctly shifting the target variable.
- **`src/models/`**: Centralizes model instantiation, chronological Train/Test splitting (70/30), training, evaluation (RMSE, RSS, R²), and selection.
- **`src/prediction/`**: Safely isolates the most recent features to generate the "Next Trading Day" forecast.
- **`src/currency/`**: Abstracts away real-time FX rate fetching and presentation-layer currency conversion.
- **`pages/`**: Streamlit application UI separated into logical pages (Dashboard, Stock Analysis, Model Analysis).

## 🛠 Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/yfinance-market-forecaster.git
   cd yfinance-market-forecaster
   ```

2. **Install Dependencies:**
   Ensure you have Python 3.9+ installed.
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the Application:**
   ```bash
   streamlit run app.py
   ```

## 🧪 Testing

The project includes a test suite powered by `pytest` to verify data validation, feature engineering boundaries (proving zero future-data leakage), and currency conversion safety.

To run the tests:
```bash
python -m pytest tests/
```
